# 白酒资本市场分析工具（交互原型）

一个根据既定产品规划制作的纯静态、可离线前端原型。页面结构对齐茅台数字化汇报中的「白酒资本市场分析工具」蓝图，组织为一个总揽页加四个分页面：

1. 总揽（功能入口、蓝图树与接入状态、行业判断、七维状态、大事记：股价核心驱动因素）
2. 产业分析（A 宏观分析：本地库+统计局九项指标 · B 产业研判：当前行业阶段信号 / 产量与消费场景结构 / 渠道出清观察 / 长期趋势研判 / 中短期数据跟踪 / 调研情况）
3. 产业比较（国内外企业：同口径对照总表、海外对标、产品结构、品牌建设、渠道情况、财务状况；含单公司六问、季度财务三图与茅台独家拆分）
4. 资本市场（分析师观点跟踪：报告观点汇总 / 目标价预测 / 盈利和收入预测；市场交易分析：2026中报CR6速览、估值、机构持仓（毛五泸+汾洋古六家）、古井贡酒渠道跟踪、交易活跃度等；C 媒体与信息源目录）
5. 舆情跟踪（行业观点、高管声音、企业新闻、重要公告等）

## 运行

直接双击 `index.html` 可以离线使用。为了获得一致的本地浏览器行为，也可以在当前目录运行：

```bash
python3 scripts/serve.py   # 默认 8766，带禁缓存头并自动注入静态资源版本号
```

然后打开 `http://127.0.0.1:8766/`。

线上部署：<https://baijiu.hedicxl.cn>（HTTPS 已启用，HTTP 自动跳转）；文件同步至云服务器 `/var/www/baijiu/`，nginx 配置在服务器 `/etc/nginx/conf.d/baijiu.conf`，独立于主站 competition.hedicxl.cn。

刷新本地数据（本地库重建 + 巨潮公告拉取）：

```bash
bash scripts/refresh.sh
```

## 主要交互

- 左侧导航与移动端底栏在五个页面间切换；旧锚点（#chain/#data/#opinions/#company）自动映射到新页面。
- 总揽页蓝图树的分支可直接点击进入对应分页面，节点标注网页接入状态。
- 产业分析页与资本市场页顶部提供页内模块导航（A/B/C/D 锚点跳转）。
- 点击产业链节点打开专业解释与证据抽屉；在繁荣、下行、修复三个反馈循环之间切换。
- 产业比较页默认三家公司同口径横向对比，可进入单公司六问与季度财务三图。
- 舆情跟踪页公告列表支持按公司筛选，链接至巨潮资讯 PDF 原文。
- 打开 AI 研究员体验受边界约束的演示回答；按 `/` 打开全局搜索；Tweaks 提供教练、研究终端、会议简报三档视图，主题、密度及加载/空/错误状态预览。
- 总揽页「大事记」按个股/行业切换：事件钉标注在日K上（点击定位到条目），收入利润复盘（行业中报卡片+22季度拟合曲线 / 个股本地库9季度柱图+同比），供需需求（行业动销-收入拟合与见底传导推演 / 个股产销存与飞天量价推演）。

## 数据说明

市场数据默认 **JYDB 优先（JyPy MySQL 主库，TLS），本地 parquet 回退**：行情/基金重仓/一致预期/目标价/交易活跃度/最新研报来自 JYDB（`scripts/jydb_source.py`，连接串从环境变量 JYDB_ENGINE_PRIMARY 或 ~/gh_quant_ui/.env 读取，不入库）；财报、宏观、估值、16 家总览仍走本地 parquet（本身由终端从 JYDB 同步）。

当前接入八类数据（另含：食饮及白酒动销与营收差拟合表 26-09-09、茅台及可比公司经营状况梳理表、古井贡酒数据库 08-31、华创集中度 PPT 与河南烟酒店周报 PDF）：价格 Excel（日度截至 2026-08-15）、本地数据库 `~/local_data`（宏观 GDP/CPI/M2/PPI/固投、三家公司季度财报、估值 08-18、基金重仓 06-30）、渠道调研 DOCX（观察期 2026-08-03 至 08-09）、国海行业报告 PDF（04-22）、国海白酒中报总结 PPT（09-03，大事记/收入利润复盘/供需拟合来源）、2023 年研究框架 PPT 和茅台数字化建设汇报 PPT。网页不是实时行情，报告观点、渠道调研和 AI 综合判断分开标注。

本地库数据由 `scripts/build_local_data.py` 生成 `data/local-data.js`（可重复运行刷新），其中含 16 家 A 股上市酒企总览快照与三家核心公司补充指标（管理费用率、ROE TTM）。公告元数据由 `scripts/fetch_announcements.py` 从巨潮资讯拉取（近三个月，含 PDF 链接），build 时自动合并。

真实数据已覆盖：宏观分析（本地库）、中短期价格与调研、渠道情况、财务状况（财报/估值/基金重仓）、报告观点汇总、重要公告。

暂无真实来源的模块以 **DEMO 虚拟示例** 填充并用虚线面板与「DEMO 模拟」徽章明确标注，待接入真实数据源后替换：区域收入结构、海外烈酒对标、产品收入结构拆分、品牌建设指标、大宗交易、北上资金、质押和两融、行业热点、高管声音、企业新闻。目标价预测、盈利和收入预测、交易活跃度已接入 JYDB 真实值。DEMO 数据不与真实值混算，不进入任何汇总结论。社零、餐饮收入、房地产开发投资、消费者信心已替换为国家统计局 2026-08-17 发布的核验值（部分序列，完整月度序列待接入 iFinD）。

价格主口径采用 `酒企批价表-260815.xlsx`（日度截至 08-15；系列酒周度列截至 08-02）。DOCX 周度文字表与其嵌入折线端点存在冲突，网页不静默混用：价格以更新至 08-15 的 Excel 为准，库存、动销、回款和政策保留渠道调研日期及“未独立核验”说明；DOCX 中的精品/生肖/十五年/1935 价格属调研文字口径，与 Excel 分列展示。

DOCX 同时是本网页的产品需求文档：高频数据前置（日/周度三价、回款、库存、动销、渠道政策）、宏观与行业数据的官方获取口径导航、公司经营四节（供需销售/产品结构/渠道建设/财务信息）、产业比较、基金持仓与舆情跟踪。

两份 PPT 的分工不同：2023 框架 PPT 作为**历史框架档案**复用其方法论（行业本质、产业变迁、价格带格局、长中短期跟踪指标体系、选股逻辑），其中批价、回款、库存等数值为 2022-2023 年口径，仅作历史对照，不与当前值混比；茅台数字化汇报 PPT 作为**跟踪体系蓝图**，定义资本市场跟踪的完整模块（产业分析、产业比较、资本市场、舆情跟踪、调研数据），总揽页蓝图树据此标注各模块的网页接入状态。

## 文件

- `index.html`：五个页面与无障碍语义结构；产业分析页含宏观分析、长期趋势研判（产业变迁/周期复盘/价格带/选股逻辑）、中短期数据跟踪（价格体系/拐点监控/系列酒全景/指标体系/观察清单）与调研情况；产业比较页含国内外对标、产品结构、品牌建设、渠道情况与财务状况；资本市场页含观点矩阵、目标价与盈利预测（DEMO）、估值与持仓；舆情跟踪页含行业观点、高管声音、企业新闻与重要公告
- `styles.css`：hedicxl.cn 风格锚点、响应式、三档视图和主题
- `data-styles.css`：数据接入、来源台账、观点时间线、公司实据、跟踪体系、模块分节带与 DEMO 面板样式
- `app.js`：导航、页内锚点、抽屉、筛选、场景切换、搜索、AI 演示、状态预览及各页面数据渲染
- `data/baijiu-data.js`：由批价 Excel 派生的价格、趋势与三价体系
- `data/research-data.js`：报告、渠道调研、2023框架PPT（trackingSystem / framework2023）与数字化蓝图（digitalBlueprint）的结构化研究事实
- `data/review-data.js`：复盘历史条目（行业与个股分列，判断与验证一一对应）
- `data/events-data.js`：大事记条目（个股/行业 × 报表/供需/价格/资金/改革驱动因素）+ 中报关键数字 + 供需拟合序列，主要来自国海中报总结 PPT（2026-09）
- `data/industry-data.js`：产业分析扩展（阶段信号推演、产量与消费场景结构、渠道出清观察）
- `data/company-deep.js`：公司深挖（茅台独家拆分模型、中报 CR6 速览、古井月度跟踪、媒体跟踪源目录）
- `scripts/jydb_source.py`：JYDB（JyPy MySQL 主库，TLS）拉取层——行情/重仓/一致预期/目标价/交易活跃度/研报，分块容错并自动回退本地 parquet
- `brand-spec.md`：设计系统与数据呈现契约
