# AI 白酒研究教练交互原型

一个根据既定产品规划制作的纯静态、可离线前端原型。参考氨纶仪表盘“判断—指标—逻辑—验证—公司”的决策顺序，把白酒研究组织为五个清晰视图：

1. 研究总览
2. 行业分析框架
3. 核心数据跟踪
4. 专家观点演化
5. 公司对比（贵州茅台 / 五粮液 / 泸州老窖）

## 运行

直接双击 `index.html` 可以离线使用。为了获得一致的本地浏览器行为，也可以在当前目录运行：

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8766/`。

## 主要交互

- 首页四张大入口卡和左侧导航明确展示完整研究功能结构。
- 点击产业链节点打开专业解释与证据抽屉。
- 在繁荣、下行、修复三个反馈循环之间切换。
- 核心数据页提供指标、趋势图、确认阈值、证伪条件、系列酒批价全景、宏观数据卡与长中短期观察清单。
- 点击七维状态、指标、图表事件或观点矩阵打开证据抽屉。
- 使用批价页筛选器和三种图表解释模式（研究员/投资含义/风险反证）。
- 数据页以树状图展示资本市场跟踪蓝图及各节点接入状态。
- 公司页默认三家公司同口径横向比较，含 A 股 16 家上市酒企总览、近三个月公告列表，也可进入单公司六问与季度财务三图。
- 打开 AI 研究员体验受边界约束的演示回答。
- 按 `/` 打开全局搜索；在“视图”中打开 Tweaks。
- Tweaks 提供教练、研究终端、会议简报三档视图，主题、密度及加载/空/错误状态预览。

## 数据说明

当前接入六类数据：价格 Excel（日度截至 2026-08-15）、本地数据库 `~/local_data`（宏观 GDP/CPI/M2/PPI/固投、三家公司季度财报、估值 08-18、基金重仓 06-30）、渠道调研 DOCX（观察期 2026-08-03 至 08-09）、国海行业报告 PDF（04-22）、2023 年研究框架 PPT 和茅台数字化建设汇报 PPT。网页不是实时行情，报告观点、渠道调研和 AI 综合判断分开标注。

本地库数据由 `scripts/build_local_data.py` 生成 `data/local-data.js`（可重复运行刷新），其中含 16 家 A 股上市酒企总览快照与三家核心公司补充指标（管理费用率、ROE TTM）。公告元数据由 `scripts/fetch_announcements.py` 从巨潮资讯拉取（近三个月，含 PDF 链接），build 时自动合并。社零、房地产开发投资、三家公司区域收入结构为固定种子随机模拟，页面统一标注“DEMO 模拟”，待官方数据替换；其余本地库字段均为真实值并保留报告期/日期。

价格主口径采用 `酒企批价表-260815.xlsx`（日度截至 08-15；系列酒周度列截至 08-02）。DOCX 周度文字表与其嵌入折线端点存在冲突，网页不静默混用：价格以更新至 08-15 的 Excel 为准，库存、动销、回款和政策保留渠道调研日期及“未独立核验”说明；DOCX 中的精品/生肖/十五年/1935 价格属调研文字口径，与 Excel 分列展示。

DOCX 同时是本网页的产品需求文档：高频数据前置（日/周度三价、回款、库存、动销、渠道政策）、宏观与行业数据的官方获取口径导航（数据页已落地为来源导航表）、公司经营四节（供需销售/产品结构/渠道建设/财务信息）、产业比较、基金持仓与舆情跟踪（后两者属待接入范围）。

两份 PPT 的分工不同：2023 框架 PPT 作为**历史框架档案**复用其方法论（行业本质、产业变迁、价格带格局、长中短期跟踪指标体系、选股逻辑），其中批价、回款、库存等数值为 2022-2023 年口径，仅作历史对照，不与当前值混比；茅台数字化汇报 PPT 作为**跟踪体系蓝图**，定义资本市场跟踪的完整模块（产业分析、产业比较、资本市场、舆情跟踪、调研数据），数据页据此标注各模块的网页接入状态。

## 文件

- `index.html`：五个视图与无障碍语义结构；框架页含产业变迁、周期复盘、价格带、选股逻辑四个历史框架模块，数据页含系列酒批价全景、长中短期指标体系、官方来源导航与数字化蓝图映射
- `styles.css`：hedicxl.cn 风格锚点、响应式、三档视图和主题
- `data-styles.css`：数据接入、来源台账、观点时间线、公司实据与跟踪体系样式
- `app.js`：导航、抽屉、筛选、场景切换、搜索、AI 演示及状态预览
- `data/baijiu-data.js`：由批价 Excel 派生的价格、趋势与三价体系
- `data/research-data.js`：报告、渠道调研、2023框架PPT（trackingSystem / framework2023）与数字化蓝图（digitalBlueprint）的结构化研究事实
- `brand-spec.md`：设计系统与数据呈现契约
